# HBG Readspeaker Helper

This plugin is a [Municipio LTS](https://github.com/municipio-se/municipio-lts)
version of the
[Helsingborg-stad Readspeaker Helper plugin](https://github.com/helsingborg-stad/readspeaker-helper).

## Fork Base

This LTS fork is based on Helsingborg stad's
[Readspeaker Helper repository](https://github.com/helsingborg-stad/readspeaker-helper)
at commit
[`4fa9fb5`](https://github.com/helsingborg-stad/readspeaker-helper/commit/4fa9fb5b124e551750ebf78d958a928dc054e20c)
from 2020-11-13. The upstream commit is not tagged as a release.
